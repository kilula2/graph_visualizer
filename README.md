# Визуализатор графов

Десктопное приложение для визуализации графов по текстовому описанию в формате списка смежности. Позволяет быстро получить наглядное изображение графа и сохранить его в SVG.

## Краткая суть проекта

Программа читает описание графа (список смежности), строит его модель, выполняет автоматическую раскладку и отображает результат в окне. Поддерживается ввод текста вручную или загрузка из файла. Результат можно сохранить в SVG.

## Инструкция по сборке

### Требования:
- C++17 или выше
- Qt 6 (модуль Widgets)
- CMake 3.16 или выше

### Сборка из командной строки:
cmake -S . -B build -DCMAKE_PREFIX_PATH="путь/к/Qt/6.x.x/gcc_64"
cmake --build build

### Сборка через Qt Creator:
Открыть CMakeLists.txt в Qt Creator
Выбрать kit с Qt 6
Нажать Run (Ctrl+R)

## Пример запуска
После сборки:
./build/GraphVisualizer

Приложение откроет окно с текстовым полем и кнопками. 
Нажать «Визуализировать» — появится изображение графа.

## Сторонние библиотеки
Qt 6 (модуль Widgets) — графический интерфейс, кроссплатформенность, отрисовка

simple_svg.hpp — генерация SVG-документов (header-only, включена в проект, не требует установки)
